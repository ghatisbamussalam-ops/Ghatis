# نسخة موقع غاطس بامسلم — ملاحظات التحديث

هذه نسخة محدّثة من ملفات الموقع الثابتة. لم يتم نشرها على GitHub أو Vercel تلقائيًا.

## ما الذي تغيّر؟
- إصلاح بنية `<head>` في الصفحة الرئيسية؛ كانت بيانات الصفحة وروابط الخطوط وملفات CSS/JavaScript موضوعة بعد بداية `<body>`.
- تحميل `site.js` باستخدام `defer` لتقليل تعطيل عرض الصفحة.
- إضافة أيقونة للموقع (`assets/favicon.svg`) وبيانات وصفية للمشاركة على الشبكات الاجتماعية لكل صفحة.
- إضافة صفحة `404.html` ثنائية اللغة.
- حذف الملاحظة التحريرية المنفصلة من مقال الشاب خالد، مع الإبقاء على قسم المصادر وروابطه.
- الحفاظ على الصفحات والمحتوى والصور الموجودة، وعدم إضافة أرقام غير موثّقة.

## طريقة النشر
1. احتفظ بنسخة احتياطية من المستودع الحالي في GitHub.
2. فك ضغط هذا الملف.
3. ارفع **محتويات المجلد** إلى جذر مستودع `Ghatis` نفسه، بحيث تبقى ملفات HTML في الجذر ويبقى مجلد `assets` باسمِه ومكانه.
4. وافق على استبدال الملفات القديمة بالنسخ الجديدة، ثم أنشئ Commit.
5. افتح Vercel وانتظر اكتمال النشر التلقائي، ثم اختبر الصفحة الرئيسية والصفحات الداخلية على الهاتف.

**مهم:** لا ترفع ملف ZIP نفسه داخل المستودع؛ يجب فك ضغطه أولًا. لم تُضَف روابط `canonical` أو `sitemap.xml` لأن عنوان النطاق النهائي للموقع لم يكن متاحًا ضمن الملفات.
